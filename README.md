# 🎮 Jogo da Velha com IA (Python)

Uma aplicação de terminal interativa do clássico Jogo da Velha (Tic-Tac-Toe) desenvolvida em Python. O jogo suporta os modos Humano vs. Humano e Humano vs. Computador, contando com lógica de tomada de decisão e bloqueio para as jogadas do computador.

## 🚀 Funcionalidades

- **Modo 2 Jogadores (PvP):** Desafie um amigo localmente no mesmo terminal.
- **Modo vs. Computador (PvE):** O computador possui lógica estratégica para:
  - Identificar e realizar vitórias imediatas.
  - Bloquear jogadas decisivas do oponente.
  - Priorizar posições estratégicas (centro e cantos).
- **Validação de Entrada:** Impede jogadas inválidas ou em posições já ocupadas.

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- Biblioteca `random` (nativa)

python main.py
